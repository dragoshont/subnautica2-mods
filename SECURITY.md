# Security Policy

## Supported Versions

Only the latest release is supported.

## Reporting a Vulnerability

Please report security concerns privately through GitHub Security Advisories if this repository is hosted on GitHub. Do not open public issues for suspected supply-chain or installer vulnerabilities.

## Scope

This project ships source-only Lua mods and a Windows installer that copies those Lua files into a local UE4SS installation. It does not ship UE4SS binaries, game files, or credentials.

The release pipeline is the only supported way to produce distributable ZIP files. Local ZIPs are for private testing only.
